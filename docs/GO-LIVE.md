# Запуск СЛОЯ с нуля (для новичка)

Время: около часа. Вам нужно: аккаунт Telegram, аккаунт GitHub, сервер и домен.

## 1. Бот
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и ник (ник заканчивается на `bot`).
2. Скопируйте **токен** (длинная строка) — это пароль бота, никому не показывайте и не вставляйте в чаты.
3. В @BotFather → `/mybots` → ваш бот → **Bot Settings** → включите **Business Mode** (режим секретаря).
   Затем **Configure Mini App / Main App** → укажите адрес из шага 3 ниже.
   (Названия пунктов Telegram иногда меняет — если не нашли, напишите мне, что видите на экране.)

## 2. Сервер и домен
- Любой VPS (виртуальный сервер) с Ubuntu и установленным Docker. Нужен домен, направленный на IP сервера (A-запись).
- Важно: сервер будет хранить чужие личные сообщения. Это персональные данные — пока что запуск для себя и друзей, а до открытого запуска нужна консультация юриста (в России — закон 152-ФЗ).

## 3. Запуск
    git clone <ваш репозиторий> sloy && cd sloy
    cp .env.example .env     # откройте .env и заполните BOT_TOKEN, WEBHOOK_SECRET (любая длинная случайная строка), WEBAPP_URL=https://ваш-домен, DOMAIN=ваш-домен
    docker compose up -d
    docker compose exec sloy node scripts/set-webhook.js

## 4. Проверка
1. Откройте бота → `/start` → должна прийти кнопка «Открыть СЛОЙ».
2. Telegram → Настройки → Telegram Business → Чат-боты → выберите бота, отметьте один тестовый чат.
3. Пусть друг напишет в этот чат «Подпиши акт до 18:00» — бот пришлёт вам уведомление.
4. Откройте Mini App → купите билет за Stars (сначала лучше с минимальной суммой), проверьте, что билет активировался.

## Если что-то не работает
Смотрите логи: `docker compose logs -f sloy` — и присылайте мне текст ошибки (токен не присылать).
