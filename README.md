# СЛОЙ — Mini App (прототип)

Статический прототип без сборки.

    python3 -m http.server 8765   # открыть http://localhost:8765

Экраны: `#/` · `#/radar` · `#/card/dan` · `#/memory` · `#/layers` · `#/paywall`.
Внутри Telegram подключается сам; снаружи работает в демо-режиме.
Архитектура и открытые вопросы: `docs/ARCHITECTURE.md`.
